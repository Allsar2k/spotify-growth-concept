# Security Policy

This repository is a static concept site and a set of Markdown documents. There is no server, no accounts and no stored visitor data.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting (**Security** tab → **Report a vulnerability**) instead of a public issue, with the file affected and steps to reproduce. You will get a reply within 7 days.

## Supported versions

Only the latest version of the `main` branch and its GitHub Pages site are supported.
